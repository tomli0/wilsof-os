# Retired migration note

This path is retained only so historical links continue to resolve. Wilsof OS is
being developed as an independent operating system. Migration or replacement of
an existing Omarchy installation is not the current project goal, and no such
system is to be changed by this work.

The former document described an older RC2 image and a superseded migration
scope. Do not use its ISO identity, unencrypted layout or unfinished-encryption
status as RC4 instructions. The original record remains available in
[Git history](https://github.com/tomli0/wilsof-os/blob/357b0b09d0333c8875a3d4d4ca8db417343d032e/docs/omarchy-transition.md).

Current Wilsof documentation:

- [Getting started](getting-started.md): exact RC4 identity and test boundaries.
- [Physical Live checklist](physical-test-checklist.md): owner evaluation and
  failure reporting, without installation or existing-OS changes.
- [Recovery](recovery.md): encrypted-root, boot and interrupted-update boundaries.
- [Source provenance](source-provenance.md): independent-implementation requirement
  and the bounded evidence review, including unresolved origin gaps.

Historical acceptance and failure evidence is preserved. This documentation
change does not modify the tested ISO, operating-system code or physical storage.
